# Contributing

Please open a pull request with one primary-source link per factual performance claim. For a new solver or paper, include its problem class, algorithm family, official paper/docs, official code link (if any), license, publication/release date, and the exact benchmark context. Distinguish open-source code from freely available binaries and commercial software.

For results, follow [the benchmark policy](docs/BENCHMARKS.md). Prefer a dated source snapshot to an undated statement such as “fastest.” Correct an existing result by documenting the old and new sources rather than silently replacing the number.
